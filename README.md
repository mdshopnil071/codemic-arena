# Codemic Arena

An AI-powered Coding Challenge and Interview Preparation Platform.

## About

Codemic Arena is a coding platform where developers and students can practice programming, solve coding challenges, participate in contests, and improve their problem-solving skills.

Our AI Learning Mentor provides educational guidance without giving complete, ready-to-submit solutions.

## Planned Features

- User Authentication
- Coding Problem Bank
- Online Code Editor
- Automated Code Execution
- Test Case Evaluation
- Timed Coding Contests
- Live Leaderboard
- AI Learning Mentor

## Technology Stack

- Frontend: React + TypeScript
- Backend: Python + FastAPI
- Database: PostgreSQL (Neon)
- Code Editor: Monaco Editor
- Code Execution: Judge0
- AI: OpenAI API
